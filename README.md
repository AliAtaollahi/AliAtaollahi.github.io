# Ali Ataollahi — Personal Website

A lightweight personal academic website focused on formal methods, programming languages,
and dependable cyber-physical systems.

## Preview locally

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Publish with GitHub Pages

Create a public repository named `AliAtaollahi.github.io`, push this directory to its `main`
branch, and GitHub Pages will serve it at <https://aliataollahi.github.io/>.

No build step or third-party JavaScript is required.
